The [Redis Cloud REST API](https://redis.io/docs/latest/operate/rc/api/api-reference) helps you manage your Redis Cloud databases programmatically.

You can use the API to:
 
- Create or manage databases  
- Define or change hosting credentials    
- Audit access via logs  
- Backup or import databases
